## APEX Money Guinée 🇬🇳

APEX Money Guinée is a mobile money transfer application built for Guinea. 
Send money instantly via Orange Money GN and MTN MoMo with low fees.

**Mission**: Make money movement instant, cheap, and accessible for 13M Guineans.

---

## ✨ Features

- **Send Money**: Transfer to Orange Money and MTN MoMo in seconds
- **Wallet**: Real-time GNF balance
- **Top-up & Withdraw**: Cash-in and Cash-out via APEX agents
- **Transaction History**: Track all payments
- **Low Fees**: 1% for APEX to APEX, 1.5% to Mobile Money
- **Secure**: PIN confirmation + CinetPay integration
- **Multi-Country Ready**: Built to expand to XOF countries later

---

## 🛠️ Tech Stack

- **Backend**: Python, Flask
- **Frontend**: HTML, CSS, JavaScript
- **Payment Gateway**: CinetPay API
- **Mobile Money**:Orange Money GN,MTMoMo
